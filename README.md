# Учёт личных финансов

Консольное приложение для учёта доходов и расходов на TypeScript. Меню работает через inquirer.

## Возможности

- Создание и удаление счетов.
- Добавление и удаление доходов и расходов.
- Просмотр истории операций и баланса.
- Экспорт операций счёта в CSV.

## Установка и запуск

Нужны Node.js 24 или новее и npm. В папке проекта:

```bash
npm ci
npm start
```

Управление — стрелками и Enter. Удаление требует подтверждения: `y` - подтвердить, `n` или Enter - отменить.

## Проверка проекта

```bash
npm run check
npm test
```

`check` проверяет типы, `test` собирает проект и запускает тесты моделей, валидации и CSV.

## Формат данных и ограничения

Суммы вводятся в рублях через точку или запятую: `250.50` или `250,50`. Внутри программы деньги хранятся в копейках. Сумма операции от 0,01 до 100 000 000 рублей.

Дата — `ГГГГ-ММ-ДД`, годы 1900–2100. Название счёта и категория обязательны, до 60 символов. Описание необязательно, до 200 символов.

Счета и операции хранятся в памяти и теряются после выхода. CSV-файлы остаются на диске, импорта из них нет.

## CSV

Каждый экспорт создаёт отдельный файл в `exports/` относительно папки запуска. Кодировка - UTF-8 с BOM, разделитель - запятая. Если Excel показывает одну колонку, при импорте выберите разделитель «запятая».
